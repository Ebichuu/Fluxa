# 质量观察生产桥接 v3 实施计划

对应规格：`docs/superpowers/specs/2026-08-05-quality-watch-bridge-v3-design.md`

## 阶段 1：统一订阅事实

1. 新增纯订阅解析器，规范化 Fluxa 本地订阅和 Torra 只读订阅。
2. 仅按 Torra ID、TMDB、媒体类型和季号精确解析；Torra 只读项使用稳定 Torra 键。
3. 任务链保留本轮 Torra 只读快照供桥接器复用，不重复访问 Torra。
4. 增加本地优先、Torra-only、重复 ID、身份冲突和标题不参与匹配的测试。

## 阶段 2：qB 文件级补证据

1. 为 qB 只读客户端增加按 Hash 缓存、单飞的文件列表读取。
2. 桥接器只为完成、唯一关联、标题无集号的剧集季包按需读取。
3. 使用明确文件集号投影桥接事实；跨季和范围冲突保持待复核。
4. 验证重复快照只访问一次同一 Hash，且不会扫描无关任务。

## 阶段 3：v3 基线与时间修正

1. 升级桥接版本为 3，摘要只汇总 v3 收据。
2. 允许水位后的精确 Symedia 成功直接创建并确认基线。
3. 让计划器只向更早的可靠证据修正 `firstSuccessAt` 和 `baselineReadyAt`。
4. 保持收据与观察单元的事务原子性及 v2 审计不变。

## 阶段 4：回归与文档

1. 覆盖 Torra-only、E01-E04 季包、Symedia 直接基线、时间修正和幂等。
2. 运行质量观察、qB、任务链专项测试，再运行后端全量测试。
3. 运行前端类型检查与生产构建，确认公开契约未新增敏感字段。
4. 更新后端 README/DESIGN 和变更校验报告。

## 完成标准

- 《狂怒追缉》类 Torra-only 精确订阅可建立四个观察单元。
- 同一快照重复运行不重复创建。
- v3 正式桥接可保持开启，自动下载继续关闭。
- 不执行历史初始化预览和任何外部写操作。
