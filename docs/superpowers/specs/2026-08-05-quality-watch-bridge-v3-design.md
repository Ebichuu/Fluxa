# 质量观察生产桥接 v3 设计

日期：2026-08-05

状态：已确认

实施边界：只修改 Fluxa；不修改 Torra、qB、Symedia；不执行历史初始化预览、搜索、下载、秒传或归档动作；自动下载继续关闭。

## 1. 目标

修复生产桥接器对 Torra 只读订阅、qB 季包文件证据和精确 Symedia 集级成功的事实遗漏。禁止通过标题模糊匹配补齐身份，也不把 Torra 只读项写入 Fluxa 本地订阅表。

验收样本《狂怒追缉》应从同一 Torra 只读订阅和四条精确集级证据建立 E01-E04 四个观察单元，进入 `observing_upgrade`；重复快照保持幂等。

## 2. 统一订阅事实

桥接器同时读取：

- Fluxa 本地追更表；
- 任务链本轮已经读取的 Torra 只读订阅快照。

解析只使用结构化字段：Torra 远端 ID、TMDB ID、媒体类型和季号。四项必须完整、唯一且与任务事实一致。Fluxa 本地订阅优先；没有本地订阅时，使用 `torra_public_subscription_key(remote_id)` 生成稳定 Torra 键。Torra 只读订阅只形成内存事实，不写入 Fluxa 订阅表。

标题、别名和相似度不得参与桥接身份判定。重复 Torra ID、身份冲突或字段缺失进入 `needs_review`。

## 3. qB 文件级补证据

桥接器仅在下列条件全部满足时读取 `/api/v2/torrents/files`：

- qB 任务已完成；
- qB 哈希唯一关联到一个剧集季目标；
- 任务标题能确认季号但没有明确集号；
- 该完成事实需要集级范围才能进入桥接。

文件列表按 qB Hash 缓存并单飞读取。桥接器只解析文件名中的明确 `SxxExx` 或集范围，不扫描所有 qB 任务，不读取内容，不使用文件名推断作品身份。跨季、无集号或范围冲突继续进入 `needs_review`。

一个季包仍只有一个 artifact owner；文件清单只把该 artifact 投影到多个集级观察目标，不产生多个底层所有者或下载动作。

## 4. Symedia 直接基线

激活水位之后的 Symedia 成功，在同时具备以下事实时，可以在没有前置观察单元的情况下创建观察单元并立即建立入库基线：

- 统一订阅身份解析成功；
- TMDB、类型、季和集明确；
- artifact 拥有唯一规范所有者；
- 成功时间来自正式 Symedia 结果且不晚于当前时间。

水位之前或等于水位的事实仍为 `historical`；缺少时间、身份或唯一所有权仍为 `needs_review`。

`firstSuccessAt` 使用该集最早的可靠成功时间；`baselineReadyAt` 使用 Symedia 入库成功时间。后续证据只能把二者修正到更早的可靠时间，不能向后移动。

## 5. 协议与审计

生产桥接协议升级为 `3`。v2 收据永久保留，不迁移、不删除；设置页桥接摘要只汇总 v3 收据。v3 使用新的收据键空间，继续包含阶段、事实类型、规范订阅键、目标、artifact、集号和正式结果身份。

收据和观察单元仍在同一 SQLite 事务内提交；外部 Torra/qB 读取在事务外完成。可重试失败维持既有独立诊断事务语义。

## 6. 安全边界

- 不执行含 999 条待复核项的历史初始化预览。
- 不自动导入 Torra 订阅，不修改任何订阅映射。
- 不启用候选下载、缺集搜索或 Torra 推送。
- qB 文件接口只读，文件名和远端 ID 不进入公开响应。
- 自动下载开关继续关闭，直到候选评分实机验收通过。

## 7. 验收

- Torra 只读订阅可通过四字段精确身份进入桥接；同名标题不能进入。
- 完成的 `S01.Complete` 季包只读取自身哈希的文件清单，并投影 E01-E04。
- 精确 Symedia E01-E04 成功可直接创建四个 `observing_upgrade` 单元。
- `firstSuccessAt` 取最早可靠成功时间，`baselineReadyAt` 取最早可靠 Symedia 入库时间。
- 重复快照不增加观察单元或收据。
- v2 收据仍可审计，但摘要只统计 v3。
- 自动下载、搜索和历史初始化均没有外部动作。
