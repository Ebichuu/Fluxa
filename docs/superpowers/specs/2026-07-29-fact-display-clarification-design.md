# 事实状态与统计说明收口设计

## 目标

修正 Symedia 保护语义、首页异常计数、qB 异常说明和 Symedia 今日记录构成，不改变现有导航、任务状态模型或外部写能力。

## 事实规则

- Symedia 只有低评分、取消或跳过覆盖、已有更优版本属于 `protected`。重复、媒体识别失败、路径不可用和执行失败均属于 `failed`。
- 同一任务只有全部结果都是保护时才派生为“已保护”；只要存在一个真实失败，任务整体进入“需要处理”。成功与保护混合仍表示本批已有明确成功，保护单元保留在文件级事实中。
- qB 保持现有公开 `status` 兼容枚举，六阶段事实进一步区分下载中、等待、无速度、卡住、校验、做种和失败。卡住或无速度的持续时间只使用 qB `last_activity`；没有可靠时间时显示“持续时间暂未确认”。
- qB 的 `active/waiting` 继续只作为当前投影，不进入永久事件台账。过期的当前事实显示“状态暂未确认”，既有成功事件不因新鲜度过期而消失。

## 统计规则

- 首页继续保留 `actionRequired` 和 `mediaActionRequired` 资源级字段，新增可选 `actionRequiredWorks` 与 `actionRequiredResources`。
- 作品数只按 `mediaType + tmdbId` 聚合；电视剧必须再包含季号。缺少可靠身份时，每个资源使用自己的链或目标标识，不按标题合并。
- 首页主结论显示“X 部作品需要处理 · 涉及 Y 个资源”，任务深链仍打开资源级列表。
- Symedia 今日记录先按稳定结果 ID 或规范文件路径去重，再拆为明确归档、低分保护、取消覆盖、真实失败和可选的状态未确认；各项合计必须等于今日记录。

## 能力状态

候选调度未启动和 Torra 自动推送关闭继续是中性能力状态，不进入异常计数，也不改变首页绿色结论。关闭推送时继续明确提示“追更仅保存，不会自动推送到 Torra”。

## 兼容性

- API 只增加可选响应字段，不修改 URL、方法、状态码和旧字段类型。
- qB 摘要只增加可选的 `lastActivity`，不改变旧 `status` 值。
- 普通页面不读取旧四段 `stages/steps`；高级诊断兼容字段保持不变。

## 验收

- Symedia 同一任务包含保护和真实失败时整体为“需要处理”。
- “未查询到媒体信息”永不显示为“已保护”。
- 同一电视剧同一季的多个分集只计一个作品，不同季分别计数；无身份资源不按标题合并。
- qB 单任务显示具体状态、可靠活动时长或“持续时间暂未确认”以及建议动作；快照过期显示“状态暂未确认”。
- Symedia 今日构成去重且分项和等于今日记录。
- 调度未启动和 Torra 自动推送关闭不进入异常。
