# Fluxa 管理端全站可读性收口设计

日期：2026-07-25
状态：待实施

## 背景

控制室第一轮收尾已经证明，小于 11px 的业务文字在桌面实机上偏弱，在 390px 手机浏览器中更难辨认。当前 `src/styles` 仍有 155 处 `8px`、`8.5px`、`9px`、`9.5px` 或 `10px` 字号，主要集中在发现页 49 处、RSS 种子库 26 处、任务中心 19 处、日历 18 处、设置 17 处和工作台共享样式 14 处。

这些声明不能直接全局替换。部分文字位于胶囊、表格、日期格、密集事实列表和移动端工具栏中，字号增大后可能造成按钮重叠、卡片增高、表头溢出或页面级横向滚动。因此本轮采用已确认的中等范围方案：保留现有工业控制台视觉，只重建管理端文字层级和必要的局部响应式布局。

## 目标

- 管理端所有需要阅读、判断或操作的文字不低于 11px。
- 正文、说明、错误、空状态和事实值优先使用 12–13px。
- 390px 宽度下不因字号放大产生页面级横向溢出、文字覆盖或按钮挤压。
- 保持首页、发现、追更、任务、日历、控制室、设置和 RSS 种子库之间一致的文字层级。
- 不改变影院大厅和 Mineradio 内嵌界面的沉浸视觉。
- 不改变数据契约、业务状态、交互权限和外部写入能力。

## 方案比较

### 方案 A：全局覆盖所有小字号

在 `.ops-page` 下统一声明 `font-size: 11px`。改动最快，但会掩盖页面私有选择器，无法区分正文与标签，也容易在表格、日历和胶囊中产生级联冲突。

### 方案 B：按语义逐类收口（采用）

逐个检查 155 处声明，按标题、正文、辅助文字、状态胶囊、数据标签和高密度表格分类。字号只在原选择器中调整；发现溢出时修改对应局部布局，不新增覆盖全站的巨型规则。

此方案改动范围可控，能同时解决可读性和响应式问题，也符合现有 CSS 文件边界。

### 方案 C：重做全部管理页面

重新定义卡片、表格和导航密度，可以获得最统一的结果，但会把字号修复扩大成全站视觉重构，回归风险和实机发布成本过高。

## 字体层级

### 11px：辅助层

适用于 eyebrow、时间、来源、状态胶囊、字段标签、按钮辅助文字、表头和短说明。字重不低于 400，行高不低于 1.35。

### 12px：默认信息层

适用于事实值、卡片描述、错误与空状态、表格数据、设置项说明、任务证据和 RSS 元数据。长文本允许换行，不能通过缩小字号解决空间不足。

### 13px 及以上：主要阅读层

适用于卡片标题、可操作条目、设置项名称、任务原因和详情正文。现有已经高于 13px 的标题不在本轮调整。

### 例外

纯图形占位、SVG 内部坐标和不承载文字的装饰元素不受字号基线影响。只要用户需要读取字符、数字或状态词，就不得继续使用 8–10px。

## 页面实施边界

- `status.css`：统一五态健康胶囊，避免各页面继续继承 8px 基线。
- `workbench.css`、`overview.css`、`shell.css`：收口共享标签、首页摘要、导航和确认框文字。
- `discover.css`：处理发现卡片、追更条目、Torra 同步、资源结果和详情面板；长标题保持两行截断。
- `tasks.css`：处理摘要、链路阶段、证据、技术详情和活动日志；窄屏工具栏继续分行。
- `calendar.css`：放大筛选、状态、日期详情和证据文字；手机 7 列月历通过行高、换行和局部尺寸消化变化，不减少海报。
- `settings.css`：放大连接组、策略、访问状态、技术开关、字段说明、错误和空状态；设置行允许增高。
- `rss-seed-library.css`：放大表头、时间、版本、来源、身份、表单和详情文字；高密度表格在窄屏使用局部滚动或换行。
- `control-room.css`：清理第一轮剩余 10px 业务文字，保持现有服务选择与事实列表结构。

## 响应式规则

- 字号放大后优先增加行高、允许换行或调整网格列，不回退到小字号。
- 弹性和网格文本项必须保留 `min-width: 0`。
- 操作按钮不得被标题覆盖；必要时按钮区换到下一行。
- 表格、时间线或服务选择需要横向空间时，只允许明确的局部容器滚动。
- 390px 视口下 `document.documentElement.scrollWidth` 不得大于视口宽度。

## 验收

- 扫描 `src/styles/*.css`，不存在面向用户文字的 8–10px 声明。
- `npm run typecheck`、`npm run build` 和前端现有测试通过。
- 后端全量测试保持通过，确认本轮没有意外改动数据契约。
- 桌面和 390×844 下检查首页、发现、追更、任务、日历、控制室、设置与 RSS 种子库。
- 核对文字未截断到无法辨认、按钮未重叠、页面无横向溢出、日历海报仍可见。
- 深色与浅色主题均保持现有对比度语义。

## 非目标

- 不重做页面信息架构或视觉主题。
- 不更换字体、颜色体系、圆角和动效语言。
- 不修改影院大厅、Mineradio、后端 API 或数据库。
- 不通过降低缩放比例、压缩字距或隐藏业务文字换取布局通过。
