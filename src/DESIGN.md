# 前端设计说明

## 模块职责

`src/` 是 Fluxa 的 React 工作台前端，负责发现、订阅、种子库、任务、活动和设置等统一操作界面。影院大厅使用 Mineradio 提供的独立视觉资源和页面边界，不继承工作台的主题与布局规则。

页面通过 `src/services/api.ts` 访问同源 Python API。前端只负责展示状态和发起明确操作，不持有外部服务密码、Token、RSS 下载地址或写权限判断。

## 信息架构

- `components/pages/`：按用户任务组织页面和详情交互。
- `components/layout/`：导航、全局作品搜索、确认弹窗和跨页面框架。
- `app/urlState.ts`：统一地址参数写入、浏览器历史项和返回滚动位置恢复。
- `services/api.ts`：统一 HTTP 请求、超时与错误处理。
- `types/`：前后端公开响应类型。
- `styles/`：工作台、发现页和影院大厅分层样式。

工作台以宽屏电脑使用为主，同时保留窄屏可操作性。深色和浅色主题共享信息层级；浅色使用克制的 macOS 磨砂玻璃风格。弹窗和浮层必须支持键盘焦点、关闭恢复和减少动态效果。

## 跨页状态与全局定位

顶部全局搜索读取 `/api/v2/search`，合并本地追更、已识别 RSS、任务、当月日历与 Emby TMDB 索引；本地没有结果时才使用 TMDB 只读补充。标准 TMDB 结果进入作品生命周期总览；无 TMDB 的本地任务显示“身份待确认”，保留公开 `chainId` 并直接进入对应任务，不构造不可用的作品详情地址。

关键页面状态写入地址参数并监听 `popstate`：任务中心保存 `userState/completedDate/chainId/targetKey` 及高级诊断条件；日历保存 `year/month/view/type/status/q/date/detail`；RSS 保存 `q/sourceId/identityStatus/window/offset`；追更保存媒体类型、关键词、年份、状态、更新时间、仅缺集条件与当前作品/季集。详情打开使用新的历史项，关闭优先返回上一状态；共享历史工具在离开前保存滚动位置，使返回列表时恢复原筛选与上下文。内部跳转必须使用 SPA 历史，复制当前 URL 可以直接定位同一筛选或任务。

## PT 获取主线

```text
发现内容 -> 本地订阅台账 -> Torra -> qBittorrent -> Torra 秒传 115 -> Symedia -> Emby
```

Torra 是第一阶段唯一 PT 获取入口。发现页和订阅详情中的“搜索资源”只调用 `GET /api/v2/rss-items` 查询本地 SQLite RSS 种子箱，用于查看候选证据，不触发下载、转存、订阅推送或其他外部写操作。

每个 RSS 来源可独立设置轮询周期。界面保留 1、3、5 分钟快捷值，同时允许输入 1–1440 分钟的自定义整数；后端执行相同范围校验。

订阅搜索会携带 TMDB、媒体类型、季号和年份查询本地种子箱：同一 TMDB 身份优先，缺少外部身份时才按标题与季号或年份保守兜底，错误 TMDB 不会混入结果。查询中、失败、无结果和结果列表直接显示在被点击的订阅条目内；发现页的同类结果插入被点击卡片所在网格位置，避免用户离开当前上下文。

订阅详情进入任务中心时携带订阅 ID、TMDB ID、季号和标题。任务中心按订阅 ID、TMDB ID + 季号、规范化标题逐级匹配；命中后显示该订阅的全部关联任务并聚焦第一条，未命中时明确说明订阅尚未形成任务。用户可随时退出聚焦并恢复普通筛选列表。

旧的 `/api/discover/resources/search` 作为后端兼容接口保留，但当前 React 工作台不调用它。115、Telegram、HDHive 和 MoviePilot 不属于当前资源搜索路径。

## 状态与安全边界

- 敏感字段仅显示“已保存”状态，前端不回显原值；只有重新输入才修改。
- 所有外部写操作由后端配置闸门最终判断，前端按钮状态不能代替服务端授权。
- `TORRA_PUSH_ENABLED=false` 时，保存订阅只进入本地台账，不应产生 Torra 后台排队或失败活动。
- Torra 第一阶段采用单向只读镜像；远端删除和双向冲突处理留到第二阶段。
- Torra-only 条目的 ID 是后端生成的不透明公开哈希；前端只原样传递，不能推导、缓存或显示原始 Torra ID。
- RSS 搜索结果不暴露下载 URL、Passkey 或 Cookie，只展示来源、标题、时间、大小、版本和季集信息。
- RSS 历史身份只通过显式“补齐身份”批量处理；GET 查询不写库，多候选保留冲突，唯一可靠匹配才补充 TMDB/IMDb。

### 2026-07-26 - 系统异常闭环与日常页面收口

任务中心新增独立系统问题面板：`/tasks?systemIssue=secupload_failures` 可直达并分享，面板展示秒传分类级批次趋势（“近三批失败数：3 → 1 → 1”）、下次自动重试时间、重试策略和“Torra 当前未返回失败文件名”能力说明，不把分类批次伪装成媒体任务卡；首页秒传关注项改为指向该深链。任务快照差值只在相同全局口径（同筛选、非定位、非分页追加）且 `version` 变化时计算，轮询显示“数据更新中”，只有后端 `ledger.artifactMigrations > 0` 时才显示身份整理数量。

追更保存反馈改用后端 `activation` 五类明确结果（已推送 / 已入队 / 仅保存 / 已存在 / 推送失败）驱动，按钮文案由 `manualFollow.state` 决定，不再用调度器运行状态猜测手动加入结果。活动日志支持 `view=important` 重点视图，后台重复同步在 limit 前折叠，人工失败永不被挤掉。

### 2026-07-26 - 发布前任务流与可分享上下文收口

任务中心的普通筛选收敛为“需要处理 / 处理中 / 已完成 / 无需处理”，身份冲突、证据不足、匹配方法和底层健康状态进入高级诊断；卡片统一显示一句话结果和唯一主操作。首页只把真实当前故障作为主结论，身份维护提示降为中性诊断，统计明确区分归档文件、完成作品/季和 qB 下载任务，并为任务、RSS、调度和服务问题生成准确深链。

顶部全局搜索新增已识别 RSS、按明确身份定位的 Emby-only、TMDB 只读补充和无 TMDB 本地任务；后者保留空 `tmdbId` 与公开 `chainId`，直接进入任务中心。任务、追更、日历、发现和 RSS 的关键筛选、月份、搜索词、展开目标及分页写入 URL，浏览器返回同时恢复滚动位置。日历搜索使用完整轻量索引而不是每天前三条预览，手机月视图保留一张海报；RSS 无结果说明已搜索、不可用和未启用来源，移动端改用种子卡片。

Torra-only 订阅、质量观察和 RSS 匹配只使用公开哈希 ID，服务端解析后也不向浏览器返回原始远端 ID。全局搜索和作品总览进入任务中心时继续携带 `userState`；普通任务阶段只显示“已确认 / 系统判断 / 待确认”等用户语言，阶段代码、活动错误码和请求 ID 仅在技术详情或高级诊断展示。发布前 390×844 与桌面深浅主题回归继续要求无页面级横向溢出；真实日历当前无条目时，海报行为由自动化样本覆盖，不能把空数据冒烟写成真实海报命中。

订阅详情质量观察与 RSS 资源流程使用独立状态、请求控制器和目标订阅守卫，避免切换作品后旧响应覆盖当前内容。动作非终态时禁止重复提交和切换目标；服务端返回动作编号后允许关闭面板并停止本地轮询，后台动作继续执行，重新进入后仍从服务端读取结果。
